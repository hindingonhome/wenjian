纹间 · 简要说明书

1.2.1 验收版 · Windows / Linux x64 · 2026.10.28

从顶栏选择一种生长机制，观看、调节、保存，再对照首饰概念与研究来源。

01 / 开始

打开与选择

运行平台包中的程序，或打开备用 HTML。点击顶栏“算法”，点选十种机制之一；页面内容同步切换。

02 / 调节

滑动，也能输入

点击“调节参数”。拖动滑块，或在数字框输入后按 Enter。相同种子便于比较形态；速度只改变推进快慢。

03 / 生长

掌握生成过程

画布工具栏可暂停、继续、单步。“新形态”会更换种子。参数面板内可输入种子或重置当前算法。

04 / 留存

五条历史与回溯

点击“保存版本”，再打开“历史”。每种算法最多五条，点击缩略图恢复参数、种子与进度；作品区也可打开关联历史。

05 / 导出

保存到本地

“导出图片”可保存算法 PNG 或当前首饰 JPG。桌面版使用系统保存窗口，取消保存不清空结果。

06 / 对照

首饰与文献

作品区提供三张 AI 角度图，可拖动或点选切换。文献区先列十篇核心研究，再列延伸材料，支持展开对应意义。

07 / 显示

主题与窗口

右上圆形按钮切换浅深主题。窗口随分辨率重排，画布按像素密度绘制；Ctrl 加号、减号、0 可缩放或复原。

08 / 收起

关闭面板

按 Escape 或点关闭按钮收起菜单、参数和历史。点顶栏空白返回顶部。关闭应用前导出想保留的图片。

验收时请留意

五条历史只保留本次会话，刷新或关闭会清空。主题偏好可保留。

生长图为研究机制演示；AI 首饰图按算法固定，参数不触发 AI 重绘。三视图不是实时三维模型，PNG/JPG 不能直接金属打印。

源泉圆体及备用 Noto Sans SC 均随包附商用许可。Linux 已做包结构校验，仍需实机启动验证；外部论文需联网。
